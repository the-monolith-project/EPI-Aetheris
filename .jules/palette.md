## 2024-05-18 - Visual Focus Indicators for Keyboard Navigation
**Learning:** Some custom interactive UI components (like styled selects, icon-only buttons, and customized checkbox labels) lacked clear focus indicators, which made them difficult to track for keyboard-only users navigating via the Tab key. The Tailwind `focus-visible` pseudo-class allows for explicit styling of the focus ring without applying it to mouse interactions, preventing visual clutter for pointer users while supporting accessibility. For elements wrapped in a label (like a custom checkbox list), using `focus-within:bg-secondary/30` on the parent label provides excellent visual feedback for the entire hit area.
**Action:** When creating new custom interactive components or overriding default browser styling, proactively apply Tailwind's `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-accent/50` classes, and consider `focus-within` on parent labels for complex inputs, ensuring a consistent and accessible keyboard navigation experience.
