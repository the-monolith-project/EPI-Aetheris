## 2024-03-24 - Accessibility (ARIA) attributes for Menu and Popover elements
**Learning:** For custom dropdowns, popovers, or menus within Astro components (such as `PanelAnalisis`, `SelectorPaneles`, `ToolbarAnalisis`), using `aria-haspopup` (with 'menu' or 'dialog' attributes) on the trigger button is critical for screen reader compatibility, but is often omitted. Also, focus state must explicitly be returned to the triggering button when closing menus (e.g. via Escape key).
**Action:** Always check components generating transient overlays/menus for appropriate `aria-haspopup` declarations on their triggers, and implement `devolverFoco` (returning focus) for robust keyboard navigation dismissals.
